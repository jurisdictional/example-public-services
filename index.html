Every public service, in one open format.

Permits, benefits, licenses and programs from your city, school district, county and state, published as Open Referral data.

Open Referral's Human Services Data Specification (HSDS) is the shared format for describing services. When every government publishes services the same way, any directory, 211 line, city portal or assistant can show them without a custom integration. This page reads one such feed, live, from the open Jurisdictional API.

See it in use

Type a U.S. street address. The page asks which governments serve it, then reads each one's services from the HSDS feed.

    Why structured data
    
        
    
          A service described in a paragraph can be read by a person.
          The same service as a record can be read by every tool.
        
    
        
    
          
    
            
    On a web page
    
            
    
          
    
          
    
            
    As an HSDS record
    
            
    
          
    
        
    
        
      
          
    • 
            Comparable.
            The same fields for every agency, so a directory can sort, filter and compare.
          
      • 
          
    • 
            Machine-readable.
            Directories, search engines and AI assistants read it directly, no scraping.
